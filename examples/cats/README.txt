Cat pack for Agent Standup (public domain / CC0, like the starter pack).
Copy the PNG files into your characters folder, then press Reload:
- lead.png = Boss, a grumpy cream cat (the lead)
- you.png = Kibbles, a bag of cat food (you)
- salem, smokey, mochi, patches, miso, biscuit, cinnamon, earl-grey, oreo = the sub-agents
- name-talk.png = open-mouth frame for each of them
64x64 px, transparent background. Drawn procedurally in Python with the help of an AI assistant.
