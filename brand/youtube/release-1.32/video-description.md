# Release video: title and description

Release announced: Agent Standup 1.32.0. Every fact below is in `README.md` or in the `## 1.32.0` entry of `CHANGELOG.md`.

## Title

**Claude Code agents as a team call, now talking in four languages** (64 characters)

French: **Des agents Claude Code en appel d'équipe, qui parlent quatre langues** (69)

## Description

```text
Agent Standup shows your Claude Code, Codex, Cowork and Mistral Vibe sessions as a live team call. Free and open source: https://agent-standup.com
This is the release video of 1.32.0, and the call you watch is the real session that made it.

The lead gives orders, sub-agents join, share their screen and report back out loud. The app only reads the session files these tools already write on your computer.

New in 1.32.0
- Natural voices in French, Spanish and Brazilian Portuguese: the Kokoro model now speaks them, with eight voices each. Two voice styles: the natural voices (the default) and the Animal Crossing babble.
- Artifacts in the call: when a session publishes an artifact, its author shares it on screen in a browser window. Click it to pin it full size.
- Cowork sessions: sessions from the Cowork tab in the Claude desktop app appear next to your Claude Code sessions, sub-agents included. Checked on macOS so far.
- The call follows the session you last touched. Click a tab to pin it there; it stays until you ask something in another session.
- The Sessions view is in sections: needs you?, your turn, working, waiting on sub-agents, idle. A session that stopped on a question shows the question on its card.
- Put a session away as done, and see its pull request on its card.
- In a replay, agents no longer talk over each other.

Three ways to run it
- VS Code extension: Extensions view, search "Agent Standup", Install.
- Terminal, no install and no editor (Node 18+): npx @double_geste/agent-standup --open
- Desktop app (macOS): download it from the release page.

Links
Website and download: https://agent-standup.com
Source code: https://github.com/Atoll92/agent-standup

How this video was made
A person typed one order in Claude Code and published the result. The session is a release meeting: the agents discuss what shipped in 1.32.0, a release that was already out. The recording replays the records of that session in the app, faster than they happened. No record was added and no text was changed. The voices are the app's natural voices, reading the first sentence of what each agent wrote.
```
