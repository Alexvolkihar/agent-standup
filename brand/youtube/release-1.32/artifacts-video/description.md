## Description

```text
Agent Standup shows your Claude Code, Codex and Mistral Vibe sessions as a live team call. New in 1.32: when an agent publishes an artifact, the real page shows up in the call. Free and open source → https://agent-standup.com

In this video three agents each build a page in a real session: a release poster, a standup bingo card, a chart of the week's commits. Each one appears in the call the moment it is published.

What you can do with a page in the call
• Click it: it opens at full size, and it works (yes, the bingo card is playable).
• Step through every page of the session with ‹ ›.
• Keep it pinned: when the agent publishes a new version, the page updates in front of you.
• Open it on claude.ai with one click.
The page is rebuilt from the session file and runs in a sealed frame: nothing is fetched from claude.ai.

Try it
• VS Code or Cursor: search "Agent Standup" in Extensions
• No install, any terminal (Node 18+): npx @double_geste/agent-standup --open
• Desktop app: https://agent-standup.com
```
